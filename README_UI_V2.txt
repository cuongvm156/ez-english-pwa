EZ English PWA - UI V2 / Phương án A

Upload đè lên repository:
- index.html
- style.css
- app.js
- sw.js
- manifest.webmanifest

Không xóa:
- icon-192.png
- icon-512.png
- .nojekyll

Đã giữ:
- Google Sheets + Apps Script API
- Main / Vocabulary / Mini Story
- Transcript 3 phần
- +/- 10 giây
- Playback Speed: 0.75x / 1x / 1.25x / 1.5x
- Once
- Repeat One (native audio.loop)
- Repeat 3x
- Lesson Loop
- Media Session / background playback
- Cache-busting V2

Lưu ý:
Lesson Loop tự chuyển file tốt khi màn hình mở. iOS có thể ngăn việc đổi sang file audio mới khi PWA bị khóa màn hình/background.
Repeat One dùng native audio.loop và phù hợp hơn cho lock-screen.
